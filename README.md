# Student Skill Gap Analyzer

Flask web application that compares student skills with requirements for selected career roles.

## Run
```bash
python -m venv .venv
```
Windows:
```bash
.venv\Scripts\activate
```
Install and run:
```bash
pip install -r requirements.txt
python app.py
```
Open `http://127.0.0.1:5000`.
